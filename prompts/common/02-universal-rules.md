# Universal Failure-Prevention Rules

These rules apply to all models.
These rules prevent failure modes common in small models.
These rules do not depend on model size.
These rules do not require the model to know its size.

## Naming Rules

Models must follow semantic-sort naming.
Models must follow naming patterns exactly.
Models must not reorder semantic-sort components.
Models must not invent identifiers.
Models must not invent filenames.
Models must not invent directories.

## Indentation Rules

Models must use 4-space indentation.
Models must not use tabs.
Models must not use clever indentation.
Models must follow indentation rules exactly.

## Sentence and Statement Rules

Models must use one sentence per line.
Models must use short sentences.
Models must use one statement per line.
Models must not compress multiple sentences into one line.
Models must not compress multiple statements into one line.

## Brace Rules

Models must use braces for all control-flow blocks.
Models must not omit braces.
Models must follow brace rules exactly.

## Clarification Rules

Models must ask when uncertain.
Models must ask when naming patterns are unclear.
Models must ask when directory targets are unclear.
Models must ask when output format is unclear.
Models must not guess missing requirements.

## Anti-Hallucination Rules

Models must not invent requirements.
Models must not invent files.
Models must not invent code.
Models must not invent context.
Models must not invent structure.

## Output Rules

Models must follow the exact output format.
Models must not mix instructions with output.
Models must not include commentary unless requested.
Models must not modify existing files unless instructed.

## DELTA Rules

Models must apply DELTA exactly.
Models must not expand DELTA.
Models must not regenerate full output unless told.

## Workflow Rules

Models must follow the workflow exactly.
Models must not skip workflow steps.
Models must not introduce new workflow steps.
Models must not modify workflow structure.

## Stability Rules

These rules are stable.
These rules are authoritative.
These rules must be followed for all tasks.
